# Resumen Completo: Introducción al Automation Testing y Fundamentos de Python

## 1. El Rol del QA Automation Tester
No somos simples verificadores de pantallas; somos ingenieros de calidad. El **Automation Tester** es el profesional encargado de **diseñar, desarrollar y mantener scripts de prueba automatizados** alineados a los requisitos del software. Su objetivo principal es la detección temprana de errores, validando continuamente el sistema (especialmente en pruebas de regresión) para mejorar la calidad, estabilidad y eficiencia en la entrega del software.

**Habilidades clave del rol:**
*   **Programación básica:** Para escribir y mantener scripts (Python, Java).
*   **Lógica y pensamiento crítico:** Para cubrir escenarios complejos y "edge cases".
*   **Atención al detalle:** Para detectar falsos positivos/negativos y sutiles bugs.
*   **Comunicación efectiva:** Para documentar defects y colaborar con Devs y POs.

**La Paradoja del Automation Testing:** Usamos software para probar software. Por lo tanto, nuestros propios scripts deben ser altamente confiables; si no, generaremos ruido en el proyecto.

## 2. Ciclo de Vida y Tipos de Pruebas Automatizables
Automatizar sin estrategia es contraproducente. El ciclo de vida de las pruebas automatizadas tiene 5 etapas: **Análisis** (¿Qué automatizamos?), **Diseño**, **Implementación**, **Ejecución** y **Mantenimiento**.

**¿Qué automatizar?** Pruebas repetitivas, de regresión, con múltiples datos o propensas a error humano.
**¿Qué NO automatizar?** Pruebas exploratorias, de usabilidad o que se ejecutarán solo una vez.

**Tipos de pruebas y herramientas:**
*   **Unitarias:** (Pytest, JUnit) - Componentes individuales.
*   **Integración:** (Selenium, RestAssured) - Interacción entre componentes.
*   **UI (Interfaz de usuario):** (Selenium, Cypress) - Comprobación visual y de flujo.
*   **API:** (Postman, RestSharp) - Servicios web/backend.
*   **Rendimiento:** (JMeter, Locust) - Velocidad y estabilidad bajo carga.

## 4. Fundamentos de Python (Nuestro lenguaje de automatización)
Python es el "idioma común" del testing moderno por su sintaxis clara (casi en inglés), su enorme comunidad y su ecosistema de librerías (como Selenium o Requests) instalables fácilmente vía `pip`.

### A. Variables, Tipos de Datos y Operadores
*   **Variables:** Contenedores de datos. Python infiere el tipo dinámicamente.
*   **Tipos básicos:** `int` (enteros), `float` (decimales), `str` (texto), `bool` (True/False).
*   **Asignación:** Uso de `=` para asignar valores. Soporta asignación múltiple (`a, b, c = 1, 2, 3`) y con operación (`contador += 1`).
*   **Operadores Aritméticos:** `+`, `-`, `*`, `/`, `%` (módulo/resto), `**` (potencia), `//` (división entera).
*   **Operadores Relacionales:** Comparan y devuelven `bool` (`>`, `<`, `==`, `!=`, `>=`, `<=`).
*   **Operadores Lógicos:** Combinan condiciones (`and`, `or`, `not`).

### B. Entrada, Procesamiento y Salida (E/P/S)
Todo programa sigue este flujo:
*   **Entrada:** `input()` captura datos del usuario (siempre devuelve un `str`).
*   **Conversión de tipos (Casting):** Es crucial convertir los datos de `input()` al tipo necesario usando `int()`, `float()`, `str()`, `bool()`.
*   **Salida:** `print()` muestra resultados, frecuentemente usando **f-strings** (`print(f"Hola {nombre}")`) para incrustar variables de forma limpia.

### C. Comentarios en el Código
Práctica esencial para la mantenibilidad. Se usan `#` para una línea, y `'''` o `"""` para múltiples líneas.

### D. Estructuras de Control (El flujo del script)
*   **Condicionales (`if`, `elif`, `else`):** Ejecutan bloques de código según se cumplan condiciones. La **indentación** (4 espacios) es obligatoria en Python para definir los bloques.
*   **Bucles:**
    *   **`for`:** Ideal cuando conocemos la cantidad de iteraciones. Se usa con secuencias o `range()`.
    *   **`while`:** Ideal cuando la repetición depende de una condición dinámica. Cuidado con los bucles infinitos.
*   **Contadores y Acumuladores:** Variables que se incrementan (`+= 1`) o suman valores (`+= i`) dentro de bucles.
*   **Sentencias de control de bucles:**
    *   `break`: Termina el bucle actual de forma anticipada.
    *   `continue`: Salta la iteración actual y pasa a la siguiente.
